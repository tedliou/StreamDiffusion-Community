# Independent fork, no upstream compatibility

This repository no longer tracks or contributes to cumulo-autumn/StreamDiffusion. The project is renamed **StreamTurbo** (Python package and CLI `streamturbo`, GitHub repository `StreamTurbo`) so it cannot be confused with the upstream `streamdiffusion` package, and the repository leaves upstream's GitHub fork network. No API compatibility with upstream is kept. The code stays under Apache-2.0, with a NOTICE file that credits the original authors and states that the files were modified.
